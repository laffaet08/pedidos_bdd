Pizzaria SQL

Script em SQL para criação de banco de dados e consultas simples de uma pizzaria.

Tecnologias

SQL (MySQL / MariaDB)

 Conteúdo

O arquivo Pizzaria.sql contém:

Criação do banco de dados pizzaria

Criação da tabela pizzaria com dados de clientes e pedidos

Consultas básicas utilizando SELECT, DISTINCT e LIKE

 Como usar

Abra o arquivo Pizzaria.sql no seu gerenciador de banco de dados (ex: MySQL Workbench, DBeaver, phpMyAdmin).

Execute os comandos para criar e consultar a base de dados.
